Deleted from the public entries: `defineCapability`, `action`, `defineScreen`,
`mount`, the capability/legacy navigation/app type exports, and Effect-specific
`Infer*` aliases. Definition inference uses `@reflex/runtime`. Removed source
implementations include the old screen contract module, string-keyed contract
navigation (`layer`/`nodes`/`implement`), `liveNodeOf`, the old focus-option
mount wrapper, and `legacyApp`. The old app composition union, navigator-key and
map conflict logic, and second `withScenarios` implementation are gone; authored
composition validates once and calls the internal `createEffectHost` lifecycle engine.

Pending legacy in `capability.ts`: `defineCapability`, the legacy `actionBuilder`
and its guard/reducer types, legacy consumer argument/error branches, and the old
state-access guard path. `author-screen.ts` and `author-actions.ts` still adapt to
that backend. `test/lifecycle.test.ts` and `packages/effect/test/capability.test.ts`
still build low-level capabilities and schema navigation factories to probe failure,
focus, cancellation and resource limits. Port these fixtures without dropping their
assertions before deleting those branches. The scoped mount/access, node instance,
registry, stack ownership, encoding and redaction machinery is shared by the target API
and must remain or be reduced in place. `LiveNode` is still the sibling consumer
contract, including live's authored action type tests.

The removed duplicate navigator-key composition test now checks the target API's
contract-key validation; raw Layer merging is no longer an author operation. The
removed explicit symbol identity type probes are replaced by constructor/definition
identity behavior tests and named-contract type checks, consistent with ADR 0020's
structural typing boundary. No experiment was deleted. The existing generic inference
limitation for scenario extensions providing required services is avoided with explicit
scenario type arguments in the identity regression; its runtime assertions are retained.
